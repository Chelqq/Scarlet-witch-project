Manual de Usuario - Interfaz de Control del Robot InMoov

Versión 6.9 - Mayo 2025

1. Introducción

Bienvenido al sistema de control para el Robot InMoov, una plataforma web diseñada para facilitar la manipulación de robots humanoides mediante una interfaz intuitiva y flexible. Este manual le guiará a través de todas las funcionalidades disponibles y le ayudará a sacar el máximo provecho del sistema.

1.1 ¿Qué es InMoov?

InMoov es un robot humanoide de tamaño real, diseñado para ser impreso en 3D y animado mediante servomotores. Creado por Gael Langevin, este proyecto de código abierto democratiza el acceso a la robótica avanzada al proporcionar planos e instrucciones gratuitas para construir un robot humanoide completo.

2. Capacidades del Sistema

Control Individual de Servomotores

Controle con precisión hasta 30 servomotores mediante una interfaz intuitiva de deslizadores.

Secuencias Personalizadas

Cree, guarde y ejecute secuencias complejas de movimientos para automatizar tareas.

Control por Gestos

Manipule el robot mediante gestos de mano capturados por la webcam de su computadora.

Conexión Flexible

Conéctese directamente por cable USB o de forma inalámbrica mediante WiFi con ESP32.

3. Requisitos del Sistema

3.1 Hardware Necesario

  • Robot: Componentes de InMoov o compatible
  • Controlador: Arduino MEGA 2560
  • Opcional: ESP32 para conexión WiFi
  • Servomotores: Hasta 30 servos estándar
  • Computadora: Con webcam (para control por gestos)
  • Alimentación: Fuente adecuada para servomotores

3.2 Software Requerido

  • Navegador: Chrome, Firefox, Safari o Edge
  • Firmware Arduino:
    • MEGA2560.ino para conexión directa
    • ESP32.ino para conexión WiFi

4. Panel de Control Principal

Nuestro sistema ofrece un panel de control intuitivo con las siguientes secciones:

  • Command & Control: Control directo de servomotores con deslizadores
  • Project Intro: Información sobre el proyecto (esta página)
  • Body Control: Control mediante gestos de mano
  • Pre programar: Gestión de secuencias programadas

5. Control Directo de Servos

La sección de Control Directo permite manipular individualmente cada servomotor con controles deslizantes precisos:

  1. Asegúrese de que el Arduino esté conectado (ver sección 8)
  2. Utilice los controles deslizantes para ajustar el ángulo de cada servo
  3. Los botones 0°, 90° y 180° permiten posicionar rápidamente en ángulos comunes
  4. El botón "Resetear todos los servos" coloca todos los servos en 90°

Nota: El cambio en los controles deslizantes se envía al robot solo cuando suelta el control, no durante el arrastre.

6. Secuencias Programadas

La sección de Secuencias Programadas permite crear, guardar y ejecutar series de movimientos:

6.1 Creación de Secuencias

  1. Haga clic en el botón "Crear Nueva Secuencia"
  2. Complete los campos del formulario:
    • Nombre: Identificador de la secuencia
    • Descripción: Detalles sobre la secuencia (opcional)
    • Pasos: Defina cada movimiento (Servo ID, Ángulo, Retardo)
    • Configuración general: Modo bucle, retardo predeterminado
  3. Haga clic en "Guardar" para almacenar la secuencia

6.2 Ejecución de Secuencias

Para ejecutar una secuencia guardada, simplemente localice la secuencia deseada en la lista y haga clic en el botón "Ejecutar". La secuencia se enviará al robot y se ejecutará paso a paso, mostrando el progreso mediante notificaciones.

7. Control por Gestos

La sección de Control por Gestos permite manipular el robot mediante movimientos de mano:

Instrucciones:

  1. Asegúrese de que su webcam esté habilitada
  2. Posicione su mano frente a la cámara
  3. El sistema detectará qué dedos están levantados cada 5 segundos
  4. Cada dedo controla un servo específico:
  • Pulgar levantado: Servo 2 a 180°
  • Índice levantado: Servo 3 a 180°
  • Medio levantado: Servo 4 a 180°
  • Anular levantado: Servo 5 a 180°
  • Meñique levantado: Servo 6 a 180°

Cuando un dedo está bajado, el servo correspondiente se posiciona en 0°.

8. Configuración de Conexión

Para controlar el robot, debe establecer una conexión con el hardware:

8.1 Conexión Directa (Arduino)

  1. Seleccione "Conexión directa a Arduino" en el panel de configuración
  2. Ingrese el puerto COM correcto (por ejemplo, COM12)
    • En Windows: Verifique en el Administrador de Dispositivos
    • En macOS: Utilice un formato como "/dev/cu.usbmodem1201"
    • En Linux: Utilice un formato como "/dev/ttyACM0"
  3. Haga clic en "Conectar"
  4. Verifique que el estado cambie a "Conectado" (verde)

8.2 Conexión WiFi (ESP32)

  1. Seleccione "Conexión WiFi a través de ESP32" en el panel de configuración
  2. Ingrese la dirección IP del ESP32 (por ejemplo, 192.168.1.100)
  3. Confirme el puerto TCP (predeterminado: 8888)
  4. Haga clic en "Conectar por WiFi"
  5. Verifique que el estado cambie a "Conectado" (verde)

9. Solución de Problemas

9.1 Problemas de Conexión

Problema Posible Causa Solución
No se puede conectar al Arduino Puerto incorrecto Verifique el puerto COM en el Administrador de Dispositivos
Arduino no encendido Compruebe la alimentación y conexión USB
Error de conexión WiFi IP incorrecta Verifique la dirección IP del ESP32
Problemas de red Compruebe que el ESP32 esté en la misma red que la computadora

9.2 Problemas con Servomotores

Problema Posible Causa Solución
Servo no responde Conexión incorrecta Verifique el cableado al pin correcto
Alimentación insuficiente Use fuente externa para los servos
Movimientos erráticos Interferencia Separe los cables de señal y alimentación

10. Preguntas Frecuentes

¿Cuántos servos puedo controlar simultáneamente?

El sistema admite hasta 30 servomotores conectados a los pines 2-31 del Arduino MEGA. Sin embargo, se recomienda no activar más de 10-12 servos al mismo tiempo para evitar sobrecarga eléctrica.

¿Qué tipo de servomotores son compatibles?

El sistema es compatible con servomotores estándar de 50Hz (periodo de 20ms). Esto incluye la mayoría de servos como SG90, MG995, etc. Los servos digitales de alta velocidad también son compatibles.

¿Cómo puedo alimentar correctamente los servomotores?

Los servomotores requieren una fuente de alimentación externa. No intente alimentarlos directamente desde el Arduino. Utilice una fuente de 5-6V con amperaje suficiente (al menos 2A para pocos servos, más de 10A para muchos servos).
